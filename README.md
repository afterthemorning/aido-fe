# AIDO-FE

AIDO (Artificial Intelligent Digital Operation) — Frontend Web Application

## Quick Start

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run build:advanced  # build with advanced mode
```

## Environment Variables

| Variable | Default | Description |
|---|---|---|
| `VITE_PREFIX` | `''` | URL base path prefix (e.g. `/aido`) |
| `VITE_IS_ENT` | `false` | Enable Enterprise features |
| `VITE_IS_PRO` | `false` | Enable Pro features |

## Tech Stack

- React 18 + TypeScript
- Ant Design 6
- Vite
- Monaco Editor
- i18next (zh_CN / en_US)
